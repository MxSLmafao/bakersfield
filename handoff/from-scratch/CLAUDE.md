# Standing instructions for Claude

## Writing style for messages

- Write all chat messages to the user in ASD-STE100 (Simplified Technical English) at about 75% compliance.
- Use short sentences. Use one instruction or fact per sentence.
- Use approved words and simple verbs. Avoid idioms and slang.
- This rule applies only to messages. Code, files, commands, commit messages and pull request text stay in normal English.
